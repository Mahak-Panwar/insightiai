# InsightAI (AI spend Audit tool)

A free web app for startup founders and engineering managers to instantly audit their AI tool spend, identify overspending, and discover savings opportunities.

## Quick Start
- Clone repo
- `npm install`
- `npm run dev`
- Deploy on Vercel/Render

## Decisions
1. Chose Next.js for SSR and recruiter‑friendly UI.
2. Used TailwindCSS for fast styling.
